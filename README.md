# Digital Attendance Tracking System — Backend Variants

This repository contains two alternative Node.js/Express backends for the live attendance dashboard:

- `backend-firebase-sheets/`: Firebase ID-token authentication and Google Sheets attendance data source.
- `backend-mock/`: the same Firebase authentication and API contract, backed by hardcoded attendance events for local development.

See each folder's README for setup instructions. Never commit Firebase service-account credentials or real staff data.
